### Cleared on inspection

- **`WITH CHECK` under the `CASE` form** — holds. The policy has no `FOR` and no `TO`, so it is `FOR ALL TO PUBLIC` and PostgreSQL reuses `USING` as `WITH CHECK`. Breaks 8 and 9 prove it.
- **`CASE` vs plain form** — identical when the GUC is unset (branch 1 at `V001__tenant.sql:29` is strictly redundant), materially different when it is `''`. The shipped form is the better one.
- **Unnamed indexes, `CONSTRAINT tenant_pkey`** — no defect. Generated names are deterministic and constraint names are schema-scoped, so no collision with a future `hrms.tenant`.
- **Grants** — `app_user` genuinely receives `SELECT/INSERT/UPDATE/DELETE` plus sequence `USAGE` via `ALTER DEFAULT PRIVILEGES FOR ROLE migration_user` (`infra/postgres/03-grants.sql:28-38`), so the IT tests RLS, not a missing grant.

## What is good

The security core of this ticket is right, and right for the right reasons.

- **The shipped policy is better than the spec's own README text.** The `CASE` form closes the empty-string hole the plain form leaves open on pooled connections. Whoever wrote it understood that a `SET LOCAL` GUC reverts to `''`, not to unset. The only fault is that the README beside it was not brought along.
- **The write-side tests are the ones that matter.** Breaks 8 and 9 assert the statement *throws* and match on `"row-level security policy"` — not a row count, which is the easy thing to write and the thing that would stay green if the policy were narrowed to `FOR SELECT`.
- **Gate C checks for the policy separately from the switch.** "RLS on, nobody policed" — the most dangerous near-miss — is caught.
- **Owner-bypass is asserted positively**, and `relrowsecurity` plus ownership are read out of the catalogue rather than inferred.
- The negative unit tests on `setForConnection` are present and correct: the method fails loudly rather than binding nothing.

The gap to approval is narrow: fix the javadoc and guard on `setForConnection`, make the
README teach the form the code actually ships, and make one test prove V001 through Flyway.
