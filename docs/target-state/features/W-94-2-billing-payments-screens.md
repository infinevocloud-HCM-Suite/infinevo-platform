## 2. Problem & Context

Once invoices are generated by `W-94.1`, there is currently no screen in the UI for:
1. The customer (Tenant Admin) to view billing history, due dates, and download official GST tax invoice PDFs.
2. The Platform Admin to view all issued invoices across tenants and record payment details (payment mode, transaction reference/UTR, payment date).

---

## 3. Scope

**In scope:**
- **Tenant Admin Screen (`/settings/billing`):**
  - Current Plan Card: Plan tier (`STARTER`, `GROWTH`, `ENTERPRISE`), Support Plan (`STANDARD`, `PRIORITY`), Active headcount vs Employee Limit badge.
  - Invoices Table: Invoice number, Billing Period, Amount, GST, Total, Status (`ISSUED`, `PAID`, `OVERDUE`), "Download PDF" action.
- **Platform Admin Screen (`/admin/tenants/:id/billing`):**
  - "Generate Invoice" action button.
  - "Record Payment" modal: Payment date, payment mode (NEFT/RTGS, UPI, Credit Card), UTR/Transaction ID, notes. Updates invoice status to `PAID`.
- Guards:
  - Tenant view: `core.tenant.view`
  - Platform admin view & payment recording: `core.billing.manage` + `PLATFORM_ONLY`

**Out of scope:**
- Third-party payment gateway integration (Razorpay/Stripe automated webhook checkout).
