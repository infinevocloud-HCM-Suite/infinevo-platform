Who can do this: the tenant admin, or anyone whose role lets them manage approval workflows.

1. Open Approvals, then Approval workflows. The Approval Definitions page has one tab per kind of request.
2. Choose the tab for the request, for example leave.
3. Click Add Step for each approval step, in order.
4. For each step pick the Approver Kind: Reporting Manager, Indirect Manager, Approver Level 1 to 3, a Role, a Named Employee or the Project Manager. Pick the role or the employee when asked.
5. Set Escalate After (Days) if a step should move on when nobody decides.
6. Click Save Definition.
