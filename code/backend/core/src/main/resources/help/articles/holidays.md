Who can do this: anyone whose role lets them read holidays.

1. Open HRMS, then Holidays. Holiday Calendars lists the calendars and the work locations each one covers.
2. Click Lookup Holidays.
3. Pick your Work Location and a Date Range.
4. Click Query. The list shows each holiday's date, day, name and Type: Regular, or Restricted (optional).
