Who can do this: the payroll officer, or anyone whose role lets them manage salary structure.

1. Open Payroll, then Salary components.
2. Choose the tab: Earnings, Deductions, Benefits or Reimbursements.
3. Click Add earning (the button names the tab you are on).
4. Enter the Code (for example BASIC), the Name and the Display Name shown on payslips.
5. Choose the Calculation Type and the Default Value. For a percentage, pick Percentage Of.
6. Set the switches that apply, such as Taxable Component, Include in CTC, Consider for ESI Contribution and Show in Employee Payslip.
7. Click Create Component. It can now be used in an employee's salary.
