Who can do this: HR, or anyone whose role lets them create employees.

1. Open People, then Employees, and click Import. The Import Employees page opens.
2. Click Download template and fill one row per employee. Keep the column names as they are.
3. Click Choose CSV and pick your file.
4. Click Dry run. Nothing is saved; the table shows each Row, its Employee number, the Result and a Message for any problem.
5. Fix the file and run the dry run again until it is clean, or use Import valid rows only to skip the rows with problems.
6. Click Import. The History table shows the run, its Status and a Result file you can Download.
