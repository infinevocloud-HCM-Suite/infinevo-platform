Who can do this: HR, or anyone whose role lets them manage leave allocations.

1. Open Leave, then Leave import.
2. Click Download Sample Template and fill it in. The file can be .xlsx or .csv.
3. Pick the Leave Year.
4. Drag the file into the box, or click the box to choose it.
5. Leave Dry Run on to check the file first, and click Start Dry Run. Nothing is saved.
6. Read Import Run Results: Total Rows, Rows Imported (Valid) and Rows Failed. If rows failed, click Download error report to see each failed row and why.
7. When the file is right, turn Dry Run off (Live) and click Execute Live Import.
8. Every run is listed in Import History with its Status, Type, Year and row counts.
