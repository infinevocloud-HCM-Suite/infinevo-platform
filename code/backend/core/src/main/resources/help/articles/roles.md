Who can do this: the tenant admin, or anyone whose role lets them read roles.

A role is a set of actions a person is allowed to do. Everyone gets their screens and buttons from the roles they hold. The system roles are Tenant administrator, HR, Manager, Payroll officer, Finance and Employee.

1. Open Organisation, then Roles.
2. The table lists each Role, its Code, whether it is a System role, and the Actions held.
3. Read a row to see what that role allows.

This screen only shows roles. To change which roles a person holds, read the article "Give a person a login and a role".
