Who can do this: anyone a request is waiting on, such as a manager.

1. Open Approvals, then Inbox. Pending Approvals lists each request with its Flow Type, Step and Waiting Since.
2. Use Filter by Flow Type to see one kind, for example leave.
3. Click View Item to read the request in full.
4. Click Approve or Reject on its row.
5. In the box, add a Comment. A reason is needed to reject. For a claim you can change the Approved Amount (INR).
6. Click Approve or Reject to confirm. The request moves to its next step or is closed.
