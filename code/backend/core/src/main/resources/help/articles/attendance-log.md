Who can do this: HR, or anyone whose role lets them read all attendance.

1. Open HRMS, then Attendance log.
2. Pick the Range, for example This week.
3. Pick one Employee, or leave it as All employees.
4. The table shows each Date with In, Out, Worked, Day Status / Remarks and where the entry came from (Origin).
