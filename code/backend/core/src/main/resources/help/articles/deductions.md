Who can do this: the payroll officer, or anyone whose role lets them manage employee deductions. Others can only see the list.

1. Open Payroll, then Deductions. Salary deductions lists each deduction's Employee, Period, Type, Amount, Reason, Status and Posted period.
2. To narrow the list, pick an Employee, a Period, a Status (Posted or Reversed) or a Type.
3. To add deductions, click Enter deductions.
4. On each line, pick the Employee, the Period (month) and the Type, and enter the Amount and a Reason. Remarks are optional. Click Add line for more, up to 500 lines at a time.
5. Read the note under each month. It says which run picks the line up. A locked month's run must be recomputed. A closed month cannot be used: enter the line for the month the note names.
6. Click Post. All lines are saved together, or none are. If one line is wrong, that row is marked and nothing is posted.
7. To undo a deduction that is Posted, click Reverse on its row, write why it is reversed and click Reverse.

The helper explains these steps but does not post or reverse a deduction for you.
