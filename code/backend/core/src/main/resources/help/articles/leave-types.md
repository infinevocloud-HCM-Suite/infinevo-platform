Who can do this: HR, or anyone whose role lets them manage leave types.

1. Open Leave, then Leave types.
2. Click Add Leave Type.
3. Enter the Name (for example Sick Leave) and a short Code (for example SL). Choose the Unit.
4. Turn on Paid Leave and Allow Half-Day if they apply. Keep Active on. Set Valid From, and Valid To if it ends.
5. Click Save.
6. On the new row, click Policy to set the yearly days. Under Entitlement & Accrual, set Annual Days and whether days accrue Monthly or Yearly.
7. Under Reset & Carry Forward, set Carry Forward and Max Carry Forward (Days). Under Eligibility Matrix, limit it to some departments, locations or a gender, or leave them empty for everyone.
8. Click Save Policy.
