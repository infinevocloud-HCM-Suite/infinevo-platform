Who can do this: the payroll officer, or anyone whose role lets them run payroll. Others can only see the history.

1. Open Payroll, then Prior payroll. Pick the financial year at the top.
2. If a banner says payroll for some months is not loaded, the tax already deducted in those months would be charged again. Load them here.
3. Click Download template and fill in the months paid before.
4. Under Upload prior payroll, click Choose a .csv file and pick your file.
5. Click Check file. File check result shows the Total rows, how many Would import and the Failed rows. If rows failed, click Download errors, fix them and check the file again.
6. Click Import and confirm. A message says how many rows were imported and how many failed.
7. Import history lists every upload. Imported months shows each employee's Gross, EPF, ESI, PT, TDS and Net. To remove a month, click Delete on its row and confirm.
