Who can do this: the payroll officer, finance, or anyone whose role lets them see pay runs.

1. Open Payroll, then Payroll runs, and open the run.
2. Click Export to Excel. The file downloads as payrun- followed by the month, for example payrun-2026-11.xlsx.
3. The file has one row per employee: Employee Number, Employee Name, Inclusion Status, Skip Reason, Paid Days, LOP Days, Gross Earnings, Total Deductions, Total Reimbursements and Net Pay.

The figures are those of the run at that moment. If you export before the run is computed, the money columns are empty; export again after Compute.
