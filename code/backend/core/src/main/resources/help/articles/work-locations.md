Who can do this: HR, or anyone whose role lets them manage the organisation.

1. Open Organisation, then Work locations.
2. Click New Location.
3. Fill in Location Name and Location Code, then the address: Address Line 1, City, State, PIN Code and Country Code.
4. Turn on Statutory Filing Address only for the one address your statutory registrations use.
5. Keep Active on so employees can be assigned to it.
6. Click Create Location.

The state matters: professional tax and holidays follow the employee's work location.
