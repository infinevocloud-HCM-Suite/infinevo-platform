title: Add a department
summary: Add, rename or remove a department such as Engineering or Sales.
roles: hr, tenant-admin
screen: /org/departments
keywords: department, departments, team, add department, org structure, organisation
---
Who can do this: HR, or anyone whose role lets them manage the organisation.

1. Open Organisation, then Departments.
2. In the box at the top, type a Code (for example ENG) and a Name (for example Engineering).
3. Click Add Departments.
4. To change one, click the pencil on its row, edit it and click Save.
5. To remove one, click the bin on its row and click Yes. If employees still use it, choose Deactivate Instead.
