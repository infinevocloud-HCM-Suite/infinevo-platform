Who can do this: HR, or anyone whose role lets them manage work-from-home policies.

1. Open Work from home, then WFH policies.
2. Click Add WFH Policy.
3. Enter a Policy Code and a Policy Name.
4. Set Annual Quota (Days), Monthly Velocity Limit (Days), Advance Notice (Days) and Max Consecutive Days.
5. Turn on Allow Half Day WFH if half days are allowed, and set Effective From.
6. Click Save Policy. To change a policy later, click Edit Policy and then Update Policy.
