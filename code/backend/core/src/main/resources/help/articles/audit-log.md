Who can do this: the tenant admin, HR, or anyone whose role lets them read the audit log.

1. Open Settings, then Audit log. The table shows each change: When, Actor, Operation, Entity, Entity id and the Changed fields.
2. To search, fill in any of these:
   - Entity: the kind of record, for example employee.
   - Actor: the person's email, or the name the log shows.
   - From and To: the date and time range.
3. Click Search. Empty the boxes and click Search again to see everything.
