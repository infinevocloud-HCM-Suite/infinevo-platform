Who can do this: HR, or anyone whose role lets them manage work-from-home allocations.

1. Open Work from home, then WFH import.
2. Click Download CSV Template and fill it in. It needs the columns employee_code, year and allocated_days.
3. Enter the Target Allocation Year, for example 2026.
4. Drag the CSV file into the box, or click the box to choose it.
5. To check the file first, turn on Dry Run (Validate without saving) and click Validate File. Nothing is saved.
6. Read the result: how many rows were imported out of the total, and the errors for any rows that failed.
7. When the file is right, turn Dry Run off and click Import Allocations.
8. Every upload is listed in Past Import History with its Mode, row counts and Status.
