title: Payroll officer
---
## Before the run
- Set the salary for new joiners and for revisions, on the employee's Salary tab. {screen:core.employee} {article:assign-salary}
- Check the reimbursement claims going into the run. {screen:payroll.claims}
- Check the deductions going into the run. {screen:payroll.deductions}

## Every month
- Create the pay run, compute it, check it and send it for approval. {screen:payroll.runs} {article:run-payroll}

## After payment
- Release the payslips. {screen:payroll.runs} {article:run-payroll}

## Every quarter
- Record the TDS challans and make the quarterly TDS return file. {screen:payroll.tds_return}

## Once a year
- Check the employees' proof of investment. {screen:payroll.proofs}

## When rules change
- Keep the salary components right. {screen:payroll.components} {article:salary-components}
- Keep the statutory settings right. {screen:payroll.settings} {article:statutory-settings}
