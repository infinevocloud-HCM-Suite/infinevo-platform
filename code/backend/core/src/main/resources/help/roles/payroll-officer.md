role: payroll-officer
title: Payroll officer
---
## At the start
- Load the payroll months paid before you moved here. {screen:payroll.prior_payroll} {article:prior-payroll} {action:payroll.run.execute}

## Before the run
- Set the salary for new joiners and for revisions, on the employee's Salary tab. {screen:core.employee} {article:assign-salary}
- Check or set an employee's TDS on their Salary tab. {screen:core.employee} {article:employee-tds} {action:payroll.tax_declaration.verify}
- Check the reimbursement claims going into the run. {screen:payroll.claims} {article:reimbursement-claims}
- Check the deductions going into the run. {screen:payroll.deductions} {article:deductions}
- Fix the failed tax recalculations. {screen:payroll.tax_recalc_failures} {article:tax-recalc-failures} {action:payroll.tax_declaration.verify}

## Every month
- Create the pay run, compute it, check it and send it for approval. {screen:payroll.runs} {article:run-payroll} {action:payroll.run.execute}
- Check the computed run before approving it. {screen:payroll.runs} {article:pay-run-review-checklist}
- Export the run to Excel to check or share it. {screen:payroll.runs} {article:pay-run-excel-export}
- Pay arrears, overtime or a one-time payout in an off-cycle run. {screen:payroll.runs} {article:off-cycle-run} {action:payroll.run.execute}
- Look at the payroll dashboard for the month and the year. {screen:payroll.dashboard} {article:payroll-dashboard}

## After payment
- Make the bank file for the approved run and send it to the bank. {screen:payroll.runs} {article:bank-file-download} {action:payroll.bank_file.export}
- Release the payslips. {screen:payroll.runs} {article:run-payroll} {action:payroll.run.execute}

## Every quarter
- Record the TDS challans and make the quarterly TDS return file. {screen:payroll.tds_return} {article:tds-return} {action:payroll.tax.manage}

## Once a year
- Check the employees' proof of investment. {screen:payroll.proofs} {article:proof-of-investment-review} {action:payroll.proof.review}
- Upload Form 16 Part A from TRACES and make Part B. {screen:payroll.settings} {article:form-16}
- Open and lock the flexible benefit plan window. {screen:payroll.settings} {article:flexible-benefits}

## When rules change
- Keep the salary components right. {screen:payroll.components} {article:salary-components} {action:payroll.structure.manage}
- Keep the statutory settings right. {screen:payroll.settings} {article:statutory-settings}
- Keep the TDS switch and the company's deductor details right. {screen:payroll.settings} {article:tds-settings}
- Keep the bank file template matching your bank's upload. {screen:payroll.settings} {article:bank-file-templates}
